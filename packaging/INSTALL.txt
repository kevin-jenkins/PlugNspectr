PlugNspectr {VERSION}  -  Windows x64 (VST3)

INSTALL
  1. Copy BOTH .vst3 folders into your VST3 plugin directory:
       C:\Program Files\Common Files\VST3\
  2. Rescan plugins in your DAW.

Both plugins appear under "Biltroy Audio".
Insert PlugNspectr Pre BEFORE the plugin you want to analyze and
PlugNspectr Post AFTER it - both on the SAME track or bus.

Requires Windows 10/11 (64-bit) and a VST3 host (Cubase, Reaper, Live, ...).
